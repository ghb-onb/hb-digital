连接你的 GitHub 账号

本站没有后端服务器，所有数据都存在本仓库的 Issues 里。管理操作需要一个只对 这个仓库 有权限的令牌。

  1. 打开 创建 Fine-grained token
  2. Repository access 只选 hb-digital
  3. Permissions → Issues: Read and write（必需）
  4. Permissions → Contents: Read and write（可选，用于「更新看板」写回 stats.json）
  5. 生成后粘贴到下面

令牌只保存在你这台设备的浏览器里，不会发送到任何第三方服务器。
