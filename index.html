这个网站怎么跑起来的

没有服务器，没有数据库，也没有账单。四层结构全部搭在 GitHub 上。

01 / 展示层

静态前端

无框架的轻量页面，GitHub Pages 免费托管。另有一个 Three.js 实时渲染的 3D 场景，作为独立实验页保留。

HTML · CSS · Three.js
02 / 数据层

Issues 当数据库

本站的公开技术反馈就是一条 Issue，自带标签、时间戳、评论与状态流转，检索分页开箱可用。

GitHub Issues API
03 / 鉴权层

最小权限令牌

管理台只持一个仅能读写本仓库 Issues 的细粒度令牌，存在标签页的 sessionStorage，关页即失效。令牌会随每次管理请求发给 GitHub API 由服务端鉴权，前端不留长期凭证。

Fine-grained PAT · sessionStorage
04 / 计算层

服务端校验 + 双路径聚合

Issue Forms 在提交时校验必填项并自动打标；看板优先读 Actions 聚合出的 stats.json 快照，快照缺失时才匿名读公开 Issues 自行汇总。

Issue Forms · stats.json 快照 · 匿名 API 兜底
