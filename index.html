02

CodeFix-Agent

找出 Python 里那几类总被忽略的错，并改掉

Python · AST · Subprocess · Pytest

源码 CI 记录
问题
代码评审里同类问题反复出现——折扣算反、可变默认参数、浮点直接比较、裸 except，人眼容易漏。
我做了
用 AST 写静态分析，实现 4 条检测规则（CF001–CF004），并为其中能自动修的写出修复逻辑。
核心实现
改写 AST 节点后重新 ast.parse 校验语法；再用子进程隔离跑 pytest，修完必须真跑通才算数。
结果
演示样例输出「修前 0/4 → 修后 4/4」；11 个用例覆盖检测、修复、验证三段链路。
03

TestPilot

把一句需求拆成一条测试流水线

FastAPI · Pydantic · SQLite · Pytest

源码 CI 记录
问题
接口测试用例靠手写，同样的结构重复很多遍，还容易漏场景。
我做了
拆成六层流水线：Planner、Generator、Executor、Collector、Analyzer、Reporter，层与层之间只用数据模型通信。
核心实现
执行层抽象成 MockExecutor，换掉它不影响其余五层——这是我在这项目里最想验证的设计。
结果
23 个用例验证六层之间的数据传递。真实浏览器执行与 LLM 用例生成属于后续计划，当前未接入

HB Digital

没有服务器，也要有完整的提交流程

HTML · CSS · JavaScript · GitHub Actions
GitHub REST API · Three.js

源码 3D 实验页
问题
想要一个零成本、能长期维护的个人站，但没有服务器，也不想为了一个表单去买后端。
我做了
